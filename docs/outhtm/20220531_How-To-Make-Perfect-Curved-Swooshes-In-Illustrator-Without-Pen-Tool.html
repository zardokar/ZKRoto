🌙 สร้างเส้นโค้ง swoosh ที่สมบูรณ์ใน Illustrator โดยไม่ใช้ Pen Tool
How to Make Perfect Curved Swooshes in Illustrator (Without Pen Tool!)

✍️ CreativeAlys📅 เผยแพร่ 2022-05-31⏱ 10:00🔇 ไม่มีเสียงพูด🧩 โหมด iw 🔗 คลิปต้นฉบับ (YouTube)

บทสรุปย่อ

คลิปนี้ไม่มีเสียงพูด เป็นการสาธิตบนจอล้วนๆ ใน Adobe Illustrator ผู้สอนเริ่มจากวาด swoosh (เส้นโค้งปลายเรียวคล้ายพระจันทร์เสี้ยว) ด้วย Pen Tool ให้ดูก่อน แล้วขึ้นข้อความว่าเป็นวิธีที่ผิดและไม่สมบูรณ์ จากนั้นสาธิตวิธีที่ไม่ใช้ Pen Tool เลย คือวาดวงกลม ใช้ Shear Tool ดัดให้เป็นวงรีเอียง คัดลอกแล้ววางสำเนาซ้อนไว้ข้างหน้า เลื่อนสำเนาออกนิดเดียว แล้วกด Minus Front ใน Pathfinder ส่วนที่เหลือคือ swoosh ที่โค้งเรียบทั้งสองขอบ ตั้งแต่ ~3:41 เป็นต้นไปผู้สอนเอา swoosh ไปหมุนแล้วคัดลอกรอบจุดศูนย์กลาง (Rotate + Copy) จนได้โลโก้ 4 แบบ ลงสี และประกอบเป็นโลโก้ "Community Logo" คำอธิบายคลิปอ้างว่าวิธีนี้ได้ swoosh ที่สมบูรณ์ทุกครั้ง โดยไม่มีเส้นสั่นหรือจุด anchor ที่ไม่เท่ากัน

โหมดเนื้อหา: เรียบเรียงใหม่ด้วยคำของผู้จัดทำ (คลิปใช้สัญญาอนุญาตมาตรฐานของ YouTube) คลิปไม่มีเสียงพูดและไม่มีคำบรรยาย เนื้อหาทั้งหมดอ่านจากภาพบนจอ ข้อความบนจอ และ chapter ในคำอธิบายคลิป

ผังภาพรวม

ในภาพนี้:

  1. แถวแรกสี่กล่องคือการเตรียมวงรีสองวง ตั้งแต่วาดวงกลม ดัดด้วย Shear วางสำเนาซ้อน จนถึงเลื่อนสำเนาออกนิดเดียว
  2. กล่อง Minus Front ที่เน้นสีคือขั้นที่ตัดวงรีสองวงจนเหลือ swoosh ซึ่งเป็นหัวใจของคลิป
  3. สองกล่องสุดท้ายคือช่วงตั้งแต่ ~3:41 ที่เอา swoosh ไปหมุนคัดลอกและลงสีจนเป็นโลโก้

ภาพนี้บอกว่าวิธีใหม่ตั้งแต่ ~1:32 ใช้เครื่องมือสำเร็จรูปต่อกันเป็นสาย ไม่มีขั้นไหนวาดเส้นด้วย Pen Tool (Pen Tool อยู่เฉพาะในตัวอย่างวิธีที่ผิดช่วงต้นคลิป)

1. ปัญหาของ Pen Tool (~0:00–1:32)

หัวข้อนี้จะพาดูอะไร: ผู้สอนวาด swoosh ด้วย Pen Tool ใน Adobe Illustrator ให้ดูก่อน แล้วขึ้นข้อความบนจอว่าเป็นวิธีที่ผิด

ใจความ: swoosh คือรูปโค้งปลายเรียวคล้ายพระจันทร์เสี้ยว มีขอบนอกและขอบในที่โค้งไปทางเดียวกัน ช่วงแรกของคลิปหลังฉากชื่อเรื่อง ผู้สอนใช้ Pen Tool ของโปรแกรม Adobe Illustrator คลิกวางจุดและดึงแขนจับ (handle) ทีละจุดเพื่อวาด swoosh สีส้มสามอัน สองอันแนวตั้งและหนึ่งอันแนวนอน ระหว่างนั้นมีไอคอนวงกลมสีแดงที่มีกากบาทสีขาวขึ้นบนจอสองครั้ง (~0:54 และ ~1:16 ไม่ได้อยู่ในภาพที่เลือกมา) และตอนท้ายช่วงขึ้นข้อความตัวใหญ่ว่า "WRONG METHOD / NOT PERFECT…" บนจอไม่มีเหตุผลบอกไว้ เหตุผลมาจากรายการ chapter ในคำอธิบายคลิป ซึ่ง chapter ช่วง 0:20 ชื่อ "Why Pen Tool Swooshes Look Uneven & Asymmetrical" แปลว่า swoosh จาก Pen Tool ดูไม่เท่ากันและไม่สมมาตร ในภาพที่ดูไม่เห็นการชี้ว่าจุดไหนของรูปผิด (ผู้จัดทำ: ช่วงนี้จึงทำหน้าที่ตั้งปัญหาไว้ให้วิธีถัดไปมาแก้)

ในภาพนี้:

  1. รูปสีส้มคือ swoosh ที่กำลังวาดอยู่ ปลายบนเรียวแหลม ส่วนโค้งด้านล่างหนากว่า
  2. จุดสีน้ำเงินเล็กๆ ตามขอบคือจุด anchor ที่ผู้สอนคลิกวางเอง เส้นตรงที่ยื่นออกจากจุดคือแขนจับที่ใช้ดัดความโค้ง
  3. ป้ายข้างเมาส์ "D: 279.65 px" เป็นตัวเลขที่ Illustrator แสดงระหว่างลาก

ภาพนี้บอกว่า Pen Tool ต้องกำหนดรูปทรงด้วยมือทุกจุด (ผู้จัดทำอธิบายเพิ่ม: ความโค้งของขอบนอกกับขอบในจึงขึ้นกับว่าวางจุดได้แม่นแค่ไหน)

ในภาพนี้:

  1. swoosh สองอันทางซ้ายเป็นแนวตั้ง อันขวาเป็นแนวนอน ทั้งหมดวาดด้วย Pen Tool
  2. กากบาทสีดำกับข้อความ "WRONG METHOD / NOT PERFECT…" เป็นข้อความที่ผู้สอนใส่ลงบนจอ

ภาพนี้บอกว่าข้อความบนจอตัดสินว่าวิธีนี้ผิดและยังไม่สมบูรณ์ และคลิปเปลี่ยนไปสอนวิธีอื่นต่อจากนี้

เอาไปใช้ทำอะไร: ใช้เป็นภาพ "ก่อน" ไว้เทียบกับ swoosh ที่สร้างจากวงรีในหัวข้อถัดไป

2. วงกลม → วงรีเอียงด้วย Shear Tool (~1:32–1:53)

หัวข้อนี้จะพาดูอะไร: ขั้นแรกของวิธีใหม่ คือทำรูปตั้งต้นเป็นวงรีเอียงโดยไม่วาดเส้นเองเลย

ใจความ: แทนที่จะวาดขอบโค้งเอง ผู้สอนเริ่มจากรูปที่โค้งเรียบอยู่แล้ว คือวงกลมสีส้มที่วาดด้วย Ellipse Tool (ผู้จัดทำอธิบายเพิ่ม: ขอบวงกลมและวงรีโค้งต่อเนื่องสม่ำเสมอเพราะโปรแกรมสร้างให้ ไม่มีจุดที่วางด้วยมือ) ต่อมาผู้สอนเลือก Shear Tool จากแถบเครื่องมือ (ป้ายชื่อขึ้นบนจอที่ ~1:44) แล้วลากบนวงกลม ผลบนจอคือวงกลมกลายเป็นวงรีที่เอียงทแยง (ผู้จัดทำอธิบายเพิ่ม: Shear คือการดัดรูปให้เอียง คล้ายดันขอบบนไปทางหนึ่งและดันขอบล่างไปอีกทาง) ระหว่างลากจะมีค่าขึ้นข้างเมาส์สองบรรทัด เช่น S: −55.2° / 48.69° ที่ ~1:46 และ S: −27.4° / 87.4° ที่ ~1:48 ค่าเหล่านี้เปลี่ยนตลอดตามการลาก คลิปไม่ได้บอกค่าสุดท้ายที่ใช้

ในภาพนี้:

  1. วงกลมสีส้มคือรูปตั้งต้น กรอบสี่เหลี่ยมสีน้ำเงินรอบรูปบอกว่ารูปนี้ถูกเลือกอยู่
  2. swoosh สีส้มสองอันที่ขอบบนเป็นของเดิมที่วาดด้วย Pen Tool ในหัวข้อที่แล้ว

ภาพนี้บอกว่าวิธีใหม่เริ่มจากรูปทรงสำเร็จรูปที่ขอบโค้งเรียบอยู่แล้ว

ในภาพนี้:

  1. วงสีเหลืองคือจุดที่ผู้สอนเน้นให้ดูว่ากำลังคลิกตรงไหน
  2. ป้าย "Shear Tool" คือชื่อเครื่องมือที่โปรแกรมแสดงเมื่อเอาเมาส์ไปชี้

ภาพนี้บอกว่าเครื่องมือที่ใช้ดัดรูปคือ Shear Tool ไม่ใช่ Pen Tool

ในภาพนี้:

  1. วงกลมทึบสีส้มคือรูปเดิมก่อนปล่อยเมาส์
  2. เส้นบางสีน้ำเงินรูปวงรีเอียงคือตัวอย่างรูปที่จะได้ถ้าปล่อยเมาส์ตอนนี้
  3. ป้ายข้างเมาส์มีค่าสองบรรทัด บรรทัดแรก S: −29.02° เป็นค่ามุม Shear ส่วนบรรทัดที่สองอ่านได้ไม่ชัด และคลิปไม่ได้อธิบาย

ภาพนี้บอกว่าการลาก Shear เปลี่ยนวงกลมเป็นวงรีเอียง และขอบยังโค้งเรียบเหมือนเดิม

ในภาพนี้:

  1. กล่องแรกคือวงกลมที่ได้จาก Ellipse Tool
  2. กล่องกลางคือการลากด้วย Shear Tool ซึ่งเป็นขั้นที่เปลี่ยนรูปทรง
  3. กล่องสุดท้ายคือวงรีเอียงที่จะใช้ในขั้นถัดไป

ภาพนี้บอกว่ารูปตั้งต้นของ swoosh ได้มาจากเครื่องมือสองตัวโดยไม่มีการวางจุดเอง

เอาไปใช้ทำอะไร: วงรีเอียงนี้คือวัตถุดิบของ swoosh ขอบนอกของ swoosh จะมาจากขอบของวงรีนี้

3. คัดลอก วางซ้อนไว้ข้างหน้า แล้วเลื่อนสำเนา (~1:53–2:08)

หัวข้อนี้จะพาดูอะไร: วิธีทำวงรีวงที่สองที่เหมือนวงแรกทุกอย่าง แล้ววางให้เหลื่อมกันเล็กน้อย

ใจความ: swoosh ต้องมีขอบสองเส้น ขอบนอกมาจากวงรีวงแรก ส่วนขอบในต้องมาจากวงรีอีกวงที่รูปเหมือนกันแต่อยู่เหลื่อมไปนิดหนึ่ง ผู้สอนเปิดเมนู Edit ซึ่งมีคำสั่ง Copy (Ctrl+C) และ Paste in Front (Ctrl+F) ชื่อ chapter "Duplicate & Align Intersecting Paths" และภาพถัดไปบอกว่าได้สำเนาที่ซ้อนอยู่ (ผู้จัดทำอธิบายเพิ่ม: Paste in Front วางสำเนาไว้ตำแหน่งเดิมพอดีและอยู่ชั้นหน้าวงเดิม) ในเมนูที่ ~1:56 บรรทัดบนสุดเขียนว่า "Undo Shear" ซึ่งยืนยันว่าขั้นก่อนหน้าคือ Shear จากนั้นผู้สอนลากสำเนาเลื่อนไปทางขวาบนเล็กน้อย ป้ายข้างเมาส์ระหว่างลากที่ ~2:06 แสดง dX: 35.64 px และ dY: −19.44 px (ค่าระหว่างลาก ไม่ทราบค่าสุดท้าย) ระยะเลื่อนนี้จะเป็นตัวกำหนดว่า swoosh ที่ได้หนาแค่ไหน (ผู้จัดทำ: ตีความจากรูปทรงที่ได้ คลิปไม่ได้บอก)

ในภาพนี้:

  1. "Undo Shear" บรรทัดบนสุดบอกว่าคำสั่งล่าสุดคือ Shear
  2. "Copy Ctrl+C" คือการคัดลอกวงรี
  3. "Paste in Front Ctrl+F" คือคำสั่งวางสำเนาไว้ที่เดิมแต่อยู่ชั้นหน้า (ผู้จัดทำอธิบายเพิ่ม)

ภาพนี้บอกว่าขั้นนี้ใช้คำสั่งในเมนู Edit ไม่ได้วาดวงรีใหม่

ในภาพนี้:

  1. วงรีสีส้มทึบคือวงเดิม
  2. เส้นขอบบางสีน้ำเงินคือสำเนาที่กำลังถูกลากไปทางขวาบน
  3. ป้าย dX: 35.64 px และ dY: −19.44 px คือระยะที่สำเนาเลื่อนจากตำแหน่งเดิม ณ จังหวะนั้นของการลาก

ภาพนี้บอกว่าสำเนาเลื่อนออกไม่มาก วงรีสองวงจึงยังทับกันเป็นส่วนใหญ่ เหลือขอบเสี้ยวหนึ่งที่ไม่ทับ

ในภาพนี้:

  1. ฝั่งซ้ายคือสภาพหลังวางสำเนา ซึ่งทับวงเดิมพอดีจนดูเป็นวงเดียว
  2. ฝั่งขวาคือสภาพหลังลากเลื่อนตามระยะที่เห็นบนจอ วงเดิมจึงโผล่ออกมาเป็นเสี้ยว

ภาพนี้บอกว่าเสี้ยวของวงเดิมที่ไม่ถูกสำเนาทับ คือรูปของ swoosh ที่จะได้

เอาไปใช้ทำอะไร: ระยะเลื่อนและทิศที่เลื่อนคือตัวปรับความหนาและทิศของ swoosh ส่วนขอบทั้งสองข้างยังมาจากวงรีที่โปรแกรมสร้าง

4. Minus Front ตัดส่วนที่ทับออก ได้ swoosh (~2:08–2:24)

หัวข้อนี้จะพาดูอะไร: ขั้นที่เปลี่ยนวงรีสองวงให้เป็น swoosh ด้วยคลิกเดียว

ใจความ: ผู้สอนเลือกวงรีทั้งสองวงพร้อมกัน แล้วไปที่ส่วน Pathfinder ในแผง Properties ด้านขวา ลูกศรสีเหลืองบนจอชี้ลงมาที่ปุ่มที่สอง และป้ายของปุ่มเขียนว่า "Click to Minus Front. Alt-click to create a Compound Shape." ผลบนจอคือเหลือรูปเสี้ยวเดียว ซึ่งก็คือ swoosh (ผู้จัดทำอธิบายเพิ่มตามการทำงานทั่วไปของ Illustrator: Minus Front เอารูปข้างหน้าไปเจาะรูปข้างหลัง ส่วนที่ทับถูกลบ และรูปข้างหน้าหายไป ขอบนอกจึงมาจากวงเดิม ขอบในมาจากสำเนา ทั้งสองขอบโค้งเรียบและปลายเรียวลงเอง) จากนั้นมีเครื่องหมายถูกขึ้นบนจอ (~2:20)

ในภาพนี้:

  1. ปุ่มสี่ปุ่มแถวบนคือปุ่มของ Pathfinder ปุ่มที่ถูกวงสีเหลืองคือ Minus Front
  2. ป้ายใต้ปุ่มคือคำอธิบายของโปรแกรม: คลิกเพื่อ Minus Front และกด Alt ค้างแล้วคลิกเพื่อทำ Compound Shape
  3. ปุ่ม Group และ Recolor ด้านล่างเป็น Quick Actions ที่ไม่ได้ใช้ในขั้นนี้

ภาพนี้บอกว่าในคลิป การตัดรูปทำจากปุ่มในแผง Properties

ในภาพนี้:

  1. รูปสีส้มคือ swoosh ที่เหลือหลังตัด ขอบนอกและขอบในโค้งไปทางเดียวกัน
  2. ปลายบนและปลายล่างเรียวแหลม (ผู้จัดทำ: เพราะขอบสองเส้นมาบรรจบกันตรงนั้น)
  3. จุดกลมสีเทาเข้มทางขวาและวงสีเหลืองเป็นตัวบอกตำแหน่งเมาส์และการคลิกของโปรแกรมอัดจอ (ผู้จัดทำตีความ)

ภาพนี้บอกว่าได้ swoosh ทั้งอันจากขั้นตอนก่อนหน้า โดยไม่เห็นการวางจุดเอง

ในภาพนี้:

  1. วงหลังกับวงหน้าเป็นข้อมูลเข้าของคำสั่ง วงหลังให้ขอบนอก ส่วนวงหน้าให้ขอบใน
  2. Minus Front ลบส่วนที่สองวงทับกัน และลบวงหน้าทิ้ง
  3. สิ่งที่เหลือคือ swoosh

ภาพนี้บอกว่ารูปทรงของ swoosh ถูกกำหนดจากวงรีสองวงกับระยะที่มันเหลื่อมกันทั้งหมด

เอาไปใช้ทำอะไร: นี่คือสูตรหลักของคลิป อยากได้ swoosh แบบไหนก็เปลี่ยนวงรีหรือระยะเลื่อน แล้วกด Minus Front ใหม่

เสริมจากผู้จัดทำ: ต่อยอดกับปอยผมใน ZKRoto

ข้อนี้เป็นความเห็นของผู้จัดทำ ไม่ได้มาจากคลิป: ZKRoto คือเครื่องมือของโปรเจกต์ผู้จัดทำที่ใช้วาดเส้นทับภาพตัวละคร และกำลังจะเพิ่มปากกาวาดเส้น vector ส่วนปอยผมสีของตัวละครที่ต้องการปลายเรียวทั้งสองข้าง ทำได้แบบเดียวกัน คือใช้เส้นโค้งสองเส้นที่เหลื่อมกันแล้วเอาพื้นที่ระหว่างกลาง แทนการวาดขอบทีละจุด ถ้าปากกาใน ZKRoto จะรองรับงานนี้ ควรมีคำสั่งตัดรูปแบบ Minus Front ด้วย

5. swoosh แบบอื่น และดัดต่อด้วย Shear (~2:24–3:41)

หัวข้อนี้จะพาดูอะไร: ใช้สูตรเดิมทำ swoosh เพิ่มอีกสองแบบ แล้วเปลี่ยนสีเป็นดำและดัดรูปต่อ

ใจความ: หลังได้ swoosh อันแรก ผู้สอนทำซ้ำสูตรเดิมของหัวข้อ 2–4 (วงกลม → Shear เป็นวงรีเอียง → วางสำเนาซ้อนแล้วเลื่อน → Minus Front ตัดส่วนที่ทับออก) อีกสองรอบ (chapter "Making 2 Dynamic Swoosh Variations") จากภาพที่ดู แต่ละรอบเริ่มจากวงกลม ดัดเป็นวงรี มีสำเนาที่เลื่อนออก แล้วได้ swoosh ใหม่ ต่างกันที่ความเอียงของวงรีและทิศที่เลื่อนสำเนา รอบที่สองได้ swoosh แนวตั้งที่บางกว่า รอบที่สามใช้วงรีที่ป้อมกว่า และเลื่อนสำเนาไปทางล่างซ้าย (ป้ายข้างเมาส์ ~3:08 อ่านได้ dX: −27 px, dY: 29.16 px โดย dX คือระยะเลื่อนแนวนอน ค่าลบคือไปทางซ้าย และ dY คือระยะแนวตั้ง ค่าบวกคือลงล่าง) จนได้ swoosh แนวนอนคล้ายอันที่วาดด้วย Pen Tool ตอนต้น จากนั้น swoosh ทั้งหมดถูกเปลี่ยนเป็นสีดำ (~3:14–3:20) และ swoosh ที่ทำเสร็จแล้วถูกดัดต่อเป็นทรงใหม่ที่เอนขึ้น มีชิ้นใหม่เพิ่มขึ้นข้างชิ้นเดิม (~3:26–3:38) chapter ช่วงนี้ชื่อ "Transforming Swooshes with the Shear Tool" ภาพตัวอย่างที่ ~4:22 (ไม่ได้อยู่ในภาพที่เลือกมา) ยังเห็น swoosh ยาวปลายแหลมอย่างน้อยสองชิ้นในแถวบน แปลว่าการดัดต่อทำมากกว่าหนึ่งชิ้น

ในภาพนี้:

  1. แถวบนคือ swoosh สามอันเดิมจาก Pen Tool
  2. แถวล่างซ้ายคือ swoosh อันแรกจากวงรี ส่วนอันถัดไปคือแบบที่สองที่บางและเอียงกว่า

ภาพนี้บอกว่าแค่เปลี่ยนวงรีกับระยะเลื่อน ก็ได้ swoosh ทรงใหม่ที่ขอบยังเรียบเหมือนเดิม

ในภาพนี้:

  1. วงรีสีส้มทึบที่แถวล่างขวาคือวงเดิมของแบบที่สาม ซึ่งป้อมกว่าสองแบบแรก
  2. เส้นขอบบางคือสำเนาที่ถูกลากไปทางล่างซ้าย ป้ายข้างเมาส์แสดง dX: −27 px และ dY: 29.16 px

ภาพนี้บอกว่าทิศที่เลื่อนสำเนากำหนดว่า swoosh จะเหลือขอบด้านไหนของวงรี

ในภาพนี้:

  1. แถวบนคือ swoosh จาก Pen Tool ที่เปลี่ยนเป็นสีดำ
  2. แถวล่างคือ swoosh สามแบบจากวิธีวงรี อันขวาสุดเป็นแนวนอน

ภาพนี้วางผลของสองวิธีไว้เทียบกันบนพื้นสีเดียวกัน

ในภาพนี้:

  1. swoosh ขวาสุดของแถวล่างมีจุด anchor สีน้ำเงินขึ้นอยู่ แปลว่าถูกเลือกอยู่
  2. ทรงของมันเอนขึ้นเป็นโค้งยาว ต่างจากสามอันทางซ้าย

ภาพนี้บอกว่า Shear ใช้ดัด swoosh ที่ตัดเสร็จแล้วได้อีกรอบ โดยขอบยังโค้งเรียบ

ในภาพนี้:

  1. สองกล่องซ้ายคือสองสิ่งที่ปรับได้ก่อนตัด ได้แก่ทรงของวงรีกับการเลื่อนสำเนา
  2. Minus Front เป็นขั้นตัดเหมือนเดิมทุกครั้ง
  3. การดัดต่อหลังตัดเป็นตัวปรับตัวที่สามที่เห็นในคลิป

ภาพนี้บอกว่า swoosh ทุกแบบในคลิปมาจากสูตรเดียว ต่างกันแค่ค่าที่ป้อนเข้าไป

เอาไปใช้ทำอะไร: ได้ชุด swoosh หลายทรงไว้เป็นชิ้นส่วนสำหรับประกอบโลโก้ในหัวข้อถัดไป

6. โลโก้ 1–2: หมุนแล้วคัดลอกรอบจุดกลาง (~3:41–5:08)

หัวข้อนี้จะพาดูอะไร: เอา swoosh ไปเรียงเป็นวงด้วย Rotate + Copy จนได้โลโก้สองแบบ

ใจความ: โลโก้แบบแรก (chapter 3:41 "Community Network Logo") เริ่มจาก swoosh หนึ่งอันกับจุดกลมสีดำหนึ่งจุด ผู้จัดทำจะเรียกชุดนี้ว่า "หนึ่งคน" เพราะจุดกลมดูเหมือนหัวและ swoosh ดูเหมือนแขนหรือลำตัว (ผู้จัดทำตีความจากรูป) ผู้สอนตั้งจุดหมุนไว้ที่กลางโลโก้ (ในภาพตัวอย่างที่ ~3:58 เห็นเป้ากากบาทของจุดหมุน แต่ไม่ได้อยู่ในภาพที่เลือกมา) แล้วเปิดหน้าต่าง Rotate ใส่มุม 120° และกดปุ่ม Copy แทน OK ปุ่ม Copy ให้ชิ้นใหม่ที่หมุนแล้ว (ผู้จัดทำอธิบายเพิ่ม: ชิ้นเดิมยังอยู่ที่เดิม) ผลที่ ~4:22 มีสามชุดรอบวง (ผู้จัดทำ: 3 × 120° = 360° จึงครบวงพอดี คลิปไม่ได้แสดงว่าทำซ้ำด้วยวิธีใด) โลโก้แบบที่สอง (chapter 4:30 "Minimalist Swirl Monogram") ใช้ swoosh อย่างเดียวและมุม 60° ได้ swoosh หลายชิ้นหมุนวนเป็นรูปก้นหอย (ผู้จัดทำ: 360° ÷ 60° = 6 ชิ้น)

ในภาพนี้:

  1. ช่อง Angle: 120° คือมุมที่หมุน
  2. ช่อง Preview ถูกติ๊กไว้ จึงเห็นตัวอย่างผลก่อนกด
  3. เมาส์อยู่บนปุ่ม Copy ซึ่งสร้างชิ้นที่หมุนแล้วเพิ่มขึ้นมาอีกชุด
  4. swoosh สีดำกับจุดกลมที่มุมล่างคือชุด "คนหนึ่งคน" ที่กำลังถูกหมุน

ภาพนี้บอกว่าการหมุนใช้ตัวเลขมุมที่แน่นอน (ผู้จัดทำ: ชิ้นที่ได้จึงห่างกันเท่ากันทุกชิ้น)

ในภาพนี้:

  1. swoosh สามชิ้นโค้งวนไปทางเดียวกันรอบจุดกลาง
  2. จุดกลมสามจุดอยู่ปลาย swoosh แต่ละชิ้น (ผู้จัดทำตีความว่าอ่านเป็นหัวของคนสามคน)

ภาพนี้บอกว่า swoosh กับจุดกลมชุดเดียว เมื่อหมุนคัดลอกก็กลายเป็นโลโก้ที่สมมาตร

ในภาพนี้:

  1. ช่อง Angle: 60° เล็กกว่าโลโก้แรกครึ่งหนึ่ง
  2. วงสีฟ้าที่ปุ่ม Copy คือจังหวะที่ผู้สอนคลิก

ภาพนี้บอกว่ามุมที่เล็กลงทำให้ได้จำนวนชิ้นมากขึ้นรอบวงเดิม

ในภาพนี้:

  1. ซ้ายคือโลโก้แบบที่หนึ่งจากหัวข้อก่อน
  2. ขวาคือ swoosh ที่หมุนทีละ 60° จนเป็นรูปก้นหอย (ผู้จัดทำคำนวณว่าครบวงที่ 6 ชิ้น)

ภาพนี้วางผลของมุม 120° กับ 60° ไว้เทียบกัน

ในภาพนี้:

  1. แท่งบนคือโลโก้แบบที่หนึ่ง มุม 120° ได้สามชิ้นรอบวง
  2. แท่งล่างคือโลโก้แบบที่สอง มุม 60° ได้หกชิ้นรอบวง

ภาพนี้บอกว่าถ้าอยากได้ n ชิ้นเท่ากันรอบวง ให้ใช้มุม 360° ÷ n (ผู้จัดทำ)

เอาไปใช้ทำอะไร: Rotate + Copy ทำให้ชิ้นซ้ำรอบวงห่างกันเท่ากันพอดี ไม่ต้องหมุนด้วยสายตา

7. โลโก้ 3–4: คนสี่คน และตราแบบวงโคจร (~5:08–6:25)

หัวข้อนี้จะพาดูอะไร: อีกสองโลโก้ที่ใช้ swoosh กับวงกลม แต่จัดวางคนละแบบ

ใจความ: โลโก้แบบที่สาม (chapter 5:08 "4-Person Colorful Community Logo") ใช้ swoosh แบบที่โค้งเป็นรูปตัว C คู่กับจุดกลมขนาดใหญ่ ในหน้าต่าง Rotate ที่ ~5:29 เห็นมุม 180° หนึ่งครั้ง และผลที่ ~5:35 มี swoosh กับจุดกลมสี่ชุดเรียงเป็นวง คลิปไม่ได้แสดงมุมของทุกรอบ จึงบอกจากภาพไม่ได้ว่าสี่ชุดได้มาอย่างไร (ผู้จัดทำ: 180° ครั้งเดียวให้แค่สองชุด จึงน่าจะมีขั้นอื่นที่ไม่เห็นในภาพ) โลโก้แบบที่สี่ (chapter 5:40 "Modern Dynamic Team Emblem") ใช้ swoosh ที่มีปลายแหลมยาวหลายชิ้นเรียงรอบจุดกลมสีดำตรงกลาง (ผู้จัดทำตีความว่าดูเหมือนวงโคจรรอบนิวเคลียส) ภาพในคลิปเห็นโลโก้นี้เพียงบางส่วน จึงนับจำนวนชิ้นไม่ได้

ในภาพนี้:

  1. โลโก้ซ้ายและโลโก้กลางคือแบบที่หนึ่งและแบบที่สองที่ทำไว้ในหัวข้อก่อน
  2. โลโก้ขวาที่ถูกเลือกอยู่คือแบบที่สาม: จุดกลมใหญ่สี่จุดกับ swoosh รูปตัว C สี่ชิ้นเรียงเป็นวง (ผู้จัดทำตีความว่าเป็นหัวกับแขน)

ภาพนี้บอกว่าแค่เปลี่ยนขนาดหัวกับทรง swoosh ก็ได้โลโก้ที่อ่านเป็นกลุ่มคนอีกแบบ

ในภาพนี้:

  1. แถวบนคือโลโก้สามแบบแรกที่ทำเสร็จแล้ว วางเรียงไว้เทียบกัน
  2. ตราด้านล่างคือแบบที่สี่ ซึ่งเห็นแค่ครึ่งบน: swoosh ปลายแหลมหลายชิ้นวนรอบจุดกลมสีดำตรงกลาง

ภาพนี้บอกว่า swoosh ชิ้นเดียวกันจัดได้ทั้งเป็นคนและเป็นวงโคจร

ในภาพนี้:

  1. ฝั่งซ้ายสรุปชิ้นส่วนของโลโก้แบบที่สาม ซึ่งใช้ swoosh รูปตัว C เป็นแขนและจุดกลมใหญ่สี่จุดเป็นหัว
  2. ฝั่งขวาสรุปชิ้นส่วนของโลโก้แบบที่สี่ ซึ่งใช้ swoosh ปลายแหลมยาววนรอบจุดกลมจุดเดียวตรงกลาง

ภาพนี้บอกว่าโลโก้สองแบบใช้ชิ้นส่วนชนิดเดียวกัน แต่ต่างกันที่ทรงของ swoosh และตำแหน่งของวงกลม

เอาไปใช้ทำอะไร: ได้แบบโลโก้ครบสี่แบบไว้ลงสีในหัวข้อถัดไป

8. ลงสีโลโก้ (~6:25–7:20)

หัวข้อนี้จะพาดูอะไร: การเปลี่ยนโลโก้สีดำให้เป็นโลโก้หลายสี

ใจความ: ผู้สอนเปิดแผง Swatches (ชุดสีสำเร็จรูป) ไว้มุมขวาบน แล้วเลือกชิ้นส่วนทีละชุด swoosh หนึ่งชิ้นกับจุดกลมของมันจะได้สีเดียวกัน ทำให้แต่ละ "คน" มีสีของตัวเอง สีที่ใช้คือแดง เขียว น้ำเงิน และเหลือง โลโก้แบบที่หนึ่งได้สามสี (แดง เขียว น้ำเงิน) โลโก้แบบที่สามได้สี่สี (เขียว เหลือง แดง น้ำเงิน) ส่วนโลโก้แบบที่สองยังเป็นสีดำ และจุดกลางของโลโก้แบบที่สี่เห็นเป็นสีแดงแล้วที่ ~7:14 และในภาพ ~7:40 ชื่อ chapter เขียนว่า "Coloring & Shading" แต่ในภาพที่ดู ผู้สอนใช้สีพื้นเรียบ ไม่เห็นการไล่เฉด

ในภาพนี้:

  1. โลโก้ซ้ายคือแบบที่หนึ่ง แต่ละคนเป็นแดง เขียว และน้ำเงิน
  2. โลโก้กลางคือแบบที่สองซึ่งยังเป็นสีดำ
  3. โลโก้ขวาคือแบบที่สาม ได้สี่สี: เขียว เหลือง แดง และน้ำเงิน
  4. แผงที่มุมขวาบนคือ Swatches ที่ใช้เลือกสี

ภาพนี้บอกว่าแต่ละชุด swoosh + จุด ได้สีเดียวกัน (ผู้จัดทำ: ทำให้อ่านเป็นกลุ่มคนหลายคนได้ชัดขึ้น)

เอาไปใช้ทำอะไร: โลโก้แบบที่สามสี่สีคือแบบที่ถูกเลือกไปทำเป็นโลโก้สุดท้าย

9. รูปทรงเรขาคณิตเอง และโลโก้สุดท้าย (~7:20–10:00)

หัวข้อนี้จะพาดูอะไร: ใช้วงรีสองวงซ้อนกันแบบเดียวกับตอนทำ swoosh มาทำรูปทรงใหม่คล้ายดาวเคราะห์มีวงแหวน แล้วดูโลโก้สุดท้าย

ใจความ: ช่วงนี้ (chapter "Designing Custom Geometric Shapes from Scratch") ในภาพตัวอย่างที่ผู้จัดทำดู (ไม่ได้อยู่ในภาพที่เลือกมา) ผู้สอนวาดวงกลมสีดำ (~7:24) บีบเป็นวงรีแบน (~7:27) หมุนให้เอียง (~7:30) และมีเส้นขอบของสำเนาวงรีอยู่ด้านในวงเดิม (~7:33) จากนั้นที่ ~7:40 ได้ชิ้นโค้งบางสองชิ้น และมีแถบคำสั่ง Ungroup ขึ้น ซึ่งบอกว่าสองชิ้นนี้เป็น group เดียวกัน จากภาพ ดูเหมือนเป็นการตัดด้วย Minus Front แบบเดียวกับ swoosh แต่ไม่เห็นปุ่มที่กดชัดเจน (ผู้จัดทำ) ต่อมาวงกลมสีแดงถูกวางไว้กลางวงแหวน และในภาพตัวอย่างช่วง ~8:14–8:38 ผู้สอนซูมเข้าไปที่จุดที่ปลายชิ้นโค้งชนขอบวงกลม (ผู้จัดทำตีความว่ากำลังจัดปลายให้พอดี) ผลคือรูปคล้ายดาวเคราะห์มีวงแหวน chapter 8:50 ชื่อ "Assembling the Final Community Logo Brand" และภาพที่ ~9:38 เป็นโลโก้สี่ชุดสี่สีเหนือตัวหนังสือ "Community Logo" ส่วนท้ายคลิปเป็นการแจกของและหน้าจอท้ายคลิป ซึ่งรายงานนี้ตัดออก

ในภาพนี้:

  1. ชิ้นโค้งบางสีดำสองชิ้นอยู่ซ้ายล่างและขวาบนในกรอบเลือกเดียวกัน ปลายเรียวทั้งคู่
  2. แถบสีฟ้าที่เขียนว่า Ungroup คือคำสั่งที่กำลังจะถูกคลิก ซึ่งบอกว่าสองชิ้นนี้เป็น group
  3. ด้านบนและด้านขวาเป็นโลโก้สีจากหัวข้อก่อน รวมถึงโลโก้แบบที่สี่ที่จุดกลางเป็นสีแดง

ภาพนี้บอกว่าวงรีสองวงซ้อนกันให้ชิ้นโค้งปลายเรียวได้มากกว่าหนึ่งชิ้นในคราวเดียว (ผู้จัดทำตีความจากผล)

ในภาพนี้:

  1. วงกลมสีแดงคือตัวดาว
  2. ชิ้นโค้งสีดำสองชิ้นอยู่ซ้ายล่างและขวาบน ปลายแต่ละชิ้นชนขอบวงกลมแดง (ลำดับหน้าหลังไม่ชัดจากภาพ)
  3. วงสีเหลืองคือตำแหน่งเมาส์ตรงจุดที่ปลายชิ้นโค้งชนขอบวงกลม

ภาพนี้บอกว่าชิ้นโค้งสองชิ้นกับวงกลมหนึ่งวงประกอบกันเป็นรูปคล้ายดาวเคราะห์มีวงแหวน

ในภาพนี้:

  1. คนสี่คนสีเขียว เหลือง แดง และน้ำเงิน มาจากโลโก้แบบที่สามที่ลงสีแล้ว
  2. ตัวหนังสือ "Community Logo" สีดำอยู่ใต้โลโก้ เป็นข้อความที่พิมพ์เพิ่ม

ภาพนี้บอกว่าส่วนที่เป็นรูปของโลโก้ (ไม่รวมตัวหนังสือ) ประกอบจาก swoosh กับวงกลม

เอาไปใช้ทำอะไร: แสดงว่าวิธีวงรีซ้อนใช้ทำได้ทั้ง swoosh เดี่ยว โลโก้ และรูปทรงอื่นที่ต้องการขอบโค้งเรียบและปลายเรียว

Key Takeaways

1.คลิปไม่มีเสียงพูด ข้อความบนจอตัดสินวิธี Pen Tool ว่า "WRONG METHOD / NOT PERFECT…" และชื่อ chapter บอกว่าผลออกมาไม่เท่ากันและไม่สมมาตร
2.สูตรหลักคือวงกลม → Shear เป็นวงรีเอียง → Copy + Paste in Front → เลื่อนสำเนาเล็กน้อย → Minus Front ได้ swoosh ที่ขอบทั้งสองข้างมาจากวงรี
3.ทรงของ swoosh เปลี่ยนได้ด้วยความเอียงของวงรี ทิศและระยะเลื่อนสำเนา และการดัดซ้ำหลังตัด (ผู้จัดทำสรุปจากภาพ)
4.Rotate ใส่มุมแล้วกด Copy ใช้เรียงชิ้นรอบวง ในหน้าต่าง Rotate ของคลิปเห็นค่า 120°, 60° และ 180°
5.หลักวงรีซ้อนกันยังใช้ทำชิ้นโค้งปลายเรียวแบบวงแหวนได้ และส่วนที่เป็นรูปของโลโก้สุดท้าย (ไม่รวมตัวหนังสือ) ประกอบจาก swoosh กับวงกลม
