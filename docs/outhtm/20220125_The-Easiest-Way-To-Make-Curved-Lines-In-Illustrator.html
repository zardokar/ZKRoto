The Easiest Way To Make Curved Lines In Illustrator

✍️ Design Made Simple📅 เผยแพร่ 2022-01-25⏱ 2:56🧩 โหมด iws 🔗 คลิปต้นฉบับ (YouTube)

TL;DR

  • Curvature Tool ใน Adobe Illustrator คือ Pen Tool ที่ "บังคับ" ให้เส้นออกมาโค้ง: แค่คลิกวางจุด เส้นจะโค้งผ่านจุดให้เองแบบลื่นๆ
  • ระหว่างวาดจะมีเส้นสีน้ำเงินบอกล่วงหน้าว่าเส้นจริงจะออกมายังไง และเส้นตัวอย่างนี้จะขยับตำแหน่งเทียบกับเส้นที่วาดไว้ เพื่อให้เส้นลื่นเสมอ
  • กด Alt = วางจุดหักมุม (เส้นตรง), Alt+Shift = ล็อกแนวตั้ง/แนวนอน, ปล่อยปุ่ม = กลับมาโค้ง เหมาะกับการลากตามขอบภาพ เช่น ตัดรูปกล้วยออกจากพื้นหลัง

เรียบเรียงใหม่ด้วยคำของผู้จัดทำ (คลิปใช้สัญญาอนุญาตมาตรฐานของ YouTube) ครอบคลุมประเด็นหลัก · โหมด iws (สั้น เน้นภาพ)

คลิกวางจุด แล้วเส้นโค้งผ่านจุดให้เอง

Curvature Tool ทำงานเหมือน Pen Tool ต่างกันแค่มันบังคับให้เส้นเป็นเส้นโค้ง ผู้สอนคลิกวางจุดไปเรื่อยๆ แล้วได้เส้นโค้งลื่นโดยไม่ต้องหัดใช้ Pen Tool ปกติให้เป็น ~0:06–0:30

Pen Tool ก็ทำได้ แต่ต้องใช้ฝีมือกว่ามาก

ผู้สอนบอกว่าใช้ Pen Tool ธรรมดาก็ทำได้ แต่ต้องใช้ฝีมือมากกว่า เพราะ Pen Tool ฝึกยาก และถึงทำได้ก็อาจไม่ลื่นสนิท (ในตัวอย่างที่วาด เขาปิดเส้นด้วยมุม ซึ่งออกมาไม่ค่อยดี) ~0:30–0:57

เส้นสีน้ำเงินคือเส้นจริงที่จะได้

เส้นที่ลากระหว่างจุดเป็นแค่เส้นต่อจุด เส้นที่จะได้จริงคือเส้นสีน้ำเงินที่แสดงล่วงหน้า และขณะเลื่อนเมาส์ เส้นตัวอย่างจะปรับตำแหน่งเทียบกับเส้นที่วาดไว้ เพื่อให้เส้นออกมาลื่นเสมอ ~1:00–1:41

Alt = จุดหักมุม, Alt+Shift = ล็อกแนวตั้ง/นอน

อยากได้เส้นตรงให้กด Alt ค้างตอนคลิก จุดนั้นจะเป็นมุม กด Alt ต่อไปเรื่อยๆ ก็วาดเส้นตรงต่อได้ ถ้ากด Alt+Shift เส้นจะล็อกตามแนวตั้งหรือแนวนอน ปล่อยปุ่มทั้งหมดเมื่อไหร่ก็กลับมาวาดเส้นโค้งได้เลย ~1:41–2:13

ปิดเส้นแล้วจุดที่ปิดยังเป็นโค้ง

ตอนปิดเส้น (close the path) เครื่องมือจะปิดให้แบบที่จุดเชื่อมยังโค้งลื่น จุดที่ปิดเป็นจุดโค้งลื่น ~2:13–2:20

ใช้ลากตามขอบภาพ เช่น ตัดกล้วยออกจากพื้นหลัง

ตัวอย่างที่เครื่องมือนี้มีประโยชน์คือการลากตามภาพหรือวัตถุ เช่น ทำ silhouette หรือตัดของออกมา ในคลิปผู้สอนลากตามรูปกล้วย เพื่อเอารูปทรงไปทำ clipping mask แล้วตัดพื้นหลังออก ~2:20–2:49

เอาไปใช้ยังไง

เสริมจากผู้จัดทำ: สิ่งที่ปากกาใน ZKRoto ควรมี

ข้อนี้เป็นความเห็นของผู้จัดทำ ไม่ได้มาจากคลิป: ถ้าจะทำปากกาวาดปอยผมทับภาพใน ZKRoto ให้ใช้ง่ายแบบนี้ ควรมี (1) คลิกวางจุดแล้วเส้นโค้งผ่านจุดเอง (2) เส้นตัวอย่างตามเมาส์ก่อนคลิก (3) เส้นตัวอย่างปรับตำแหน่งเทียบกับเส้นเดิมเพื่อให้ลื่น (4) Alt = จุดหักมุม และ Alt+Shift = ล็อกแนว (5) ปิดเส้นแล้วจุดที่ปิดยังโค้ง ซึ่ง PenVec ปี 2012 มีแค่เส้นตรงต่อจุดกับรูปหลายเหลี่ยม
