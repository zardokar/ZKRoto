## TL;DR
- Adobe Illustrator's Curvature Tool works like the Pen Tool but forces curved segments: you click to place points and the path bends smoothly through them without having to learn the regular Pen Tool properly.
- A blue preview shows the segment that will actually be created; while the mouse moves, the preview changes relative to the earlier path so the whole line stays smooth.
- Alt = corner point / straight segments; Alt+Shift = straight segments locked to vertical / horizontal; releasing the keys returns to curves. Typical use: tracing over an image (a banana) to build a clipping-mask shape.

## Key Points
1. (0:06-0:30) Curvature Tool = Pen Tool that forces curves; clicking points produces a smooth, fluid path automatically (frame 01).
2. (0:30-0:57) The same path is possible with the regular Pen Tool but takes a lot more skill (steep learning curve), and even then it may not come out perfectly smooth; the presenter ended his Pen Tool attempt with a corner that did not look good.
3. (1:00-1:41) After two clicks, the straight line between the points is NOT the result; the blue indicator previews the segment that will be created. Moving the mouse changes the blue path relative to the earlier path so the result stays smooth (frames 02-04).
4. (1:41-2:13) Hold Alt while clicking to make a corner point and straight segments; Alt+Shift locks straight segments to the vertical / horizontal axis; let go of the keys to return to curves (frames 05-06).
5. (2:13-2:20) Closing the path makes the closing anchor point smooth automatically (frame 07).
6. (2:20-2:49) Example use: tracing over an image or subject (silhouette, cut-out); the presenter traces a banana to make a shape for a clipping mask that removes the background (frames 08-09).
